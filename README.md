# Ejercicio-16-Programacion-2
Resolución del ejercicio N°16 de programación 2.
El programa simula como un personaje de videojuego pierde y recupera puntos de vida, gana experiencia y sube de nivel.
El personaje pierde x puntos de vida, y el programa simula cuantos va a recuperar por subir de nivel y por curación del personaje en si.
Para subir de nivel el personaje requiere 100 puntos de expereiencia.
